隐私政策

生效日期：2026 年 10 月 29 日

这个应用是什么

「亦有径发布工具」是频道作者自用的视频发布程序，运行在作者自己的电脑上，用来把自己制作的视频上传到亦有径 YouTube 频道。它不对外提供服务，没有其他用户。

访问哪些数据

经频道所有者本人授权后，程序通过 YouTube Data API 上传视频、缩略图和字幕，设置标题、简介和发布时间，管理频道自己的播放列表，并读取频道名称和统计数字用于确认授权。程序不读取任何观众的个人信息、评论或私信。

数据如何存储

OAuth 授权令牌只保存在作者本人电脑的本地文件中，不上传到任何服务器，也不与任何第三方共享。视频和相关文案本来就是作者自己制作的内容。

Google 用户数据的使用

本应用对从 Google API 获得的信息的使用和传输，遵守 Google API 服务用户数据政策，包括其中的「有限使用」要求。

撤销授权

随时可以在 Google 账号的第三方应用权限页面撤销本应用的访问权限。撤销后程序无法再访问频道。

联系方式

如有问题，请通过 YouTube 频道「亦有径」的主页联系作者。

Privacy Policy

Effective October 29, 2026

The "YYJ Publisher" is a private tool run by the owner of the 亦有径 YouTube channel on their own computer. It has no other users. With the channel owner's authorization, it uses the YouTube Data API to upload the owner's own videos, thumbnails and captions, set titles, descriptions and publish times, manage the channel's own playlists, and read the channel name and statistics to confirm authorization. It does not access any viewer's personal data, comments or messages.

OAuth tokens are stored only in a local file on the owner's computer. They are never sent to any server or shared with any third party. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at myaccount.google.com/permissions. For questions, contact the author through the 亦有径 YouTube channel page.
